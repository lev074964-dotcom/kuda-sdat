# Куда сдать

Сайт на Python, который по фотографии определяет материал отхода и подсказывает, куда его сдавать. Распознавание устроено как в [Google Teachable Machine](https://teachablemachine.withgoogle.com/train/image): снимок приводится к 224×224, цвета переводятся в диапазон от −1 до 1, а классы читаются из `labels.txt`.

Встроенная модель отличает шесть материалов: пластик, бумагу, картон, стекло, металл и смешанные отходы. Для каждого есть памятка: какой бак выбрать, как подготовить предмет и что туда не класть. Правила двора отличаются, поэтому ответ нужно сверить с памяткой своего оператора.

Локально сайт открывается по адресу [http://127.0.0.1:8642](http://127.0.0.1:8642).

## Запуск

Нужен Python 3.12.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8642
```

Первый запуск подгружает TensorFlow и модель, это занимает несколько секунд. Дальше можно снять предмет камерой, загрузить фото или нажать готовый пример.

## Своя модель Teachable Machine

1. Откройте [Teachable Machine → Image](https://teachablemachine.withgoogle.com/train/image).
2. Соберите классы. Удобные имена: `plastic`, `paper`, `cardboard`, `glass`, `metal`, `trash`, `organic`. Подойдут и русские названия: «пластик», «бумага», «картон», «стекло», «металл», «органика».
3. Нажмите Export → TensorFlow → Keras и скачайте архив.
4. Положите `keras_model.h5` и `labels.txt` в папку `model/`. Если рядом лежит `keras_model.keras`, файл `.h5` имеет приоритет.
5. Перезапустите сервер.

Незнакомый класс модель всё равно покажет, но без готовой памятки: для него сайт попросит проверить правила оператора. Если старый файл `keras_model.h5` не открывается в TensorFlow 2.21, оставьте встроенный `keras_model.keras`.

## Как устроена встроенная модель

Скрипт `scripts/train.py` обучает MobileNetV2 на [TrashNet](https://github.com/garythung/trashnet) (Mindy Yang, Gary Thung, 2016): стекло, бумага, картон, пластик, металл и прочие отходы. Снимки в наборе сняты на светлом фоне, поэтому бытовое фото с несколькими предметами модель узнаёт хуже. Точность на отложенной части набора записана в `model/metrics.json` и показана внизу страницы.

Повторное обучение, если датасет уже распакован:

```bash
python scripts/train.py --data /tmp/trashnet/dataset-resized
```
